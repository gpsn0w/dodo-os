Направи DODO OS за твоя Samsung или Xiaomi

DODO OS е отворен код. Смени device tree-то с това за твоя телефон, компилирай и публикувай своя версия в GitHub. Ето целия път — за Samsung и Xiaomi.

1

Подготви компютъра

Компилацията става само на Linux — Windows и Mac не стават. Най-лесно е Ubuntu 22.04 или 24.04 (или в dual-boot / виртуална машина). Нужни са ти:

💻 16 GB RAM (32 GB е по-добре) · ~300 GB свободно място (идеално SSD) · бърз интернет (сваля се над 100 GB код).

Отвори терминала и инсталирай нужните инструменти:

sudo apt update
sudo apt install -y git-core gnupg flex bison build-essential zip curl \
  zlib1g-dev libc6-dev-i386 libncurses5 x11proto-core-dev libx11-dev \
  lib32z1-dev libgl1-mesa-dev libxml2-utils xsltproc unzip fontconfig \
  python3 openjdk-17-jdk

Инсталирай и инструмента repo (с него се тегли сорс кодът) и adb/fastboot:

sudo apt install -y android-sdk-platform-tools-common adb fastboot
mkdir -p ~/bin
curl https://storage.googleapis.com/git-repo-downloads/repo > ~/bin/repo
chmod a+x ~/bin/repo
export PATH=~/bin:$PATH

Накрая кажи на git кой си (иначе repo се оплаква):

git config --global user.name "Твоето Име"
git config --global user.email "ti@example.com"
2

Отключи bootloader-а на телефона

Bootloader-ът е „ключалката", която по подразбиране пуска само официалната фабрична система. Трябва да я отключиш, за да сложиш своя.

Първо на телефона: Настройки → Относно телефона → чукни 7 пъти на „Номер на версията", за да отключиш „За програмисти". После в За програмисти включи OEM unlocking и USB debugging.

Xiaomi: влез с Mi акаунт на телефона (Настройки → „Статус на Mi Unlock"), после пусни Mi Unlock Tool на Windows компютър. Xiaomi кара да чакаш 7–30 дни, преди да позволи отключването — няма как да се избегне.

Samsung: стига да включиш OEM unlocking. Samsung не ползва fastboot — флашва се със специална програма Odin (Windows) или Heimdall (Linux).

⚠️ Отключването трие целия телефон (снимки, чатове, всичко). Направи си бекъп преди това.

3

Намери „дърветата" за твоя точен модел

Всеки телефон си има кодово име (codename). Виж го така (при включено USB debugging и закачен телефон):

adb shell getprop ro.product.device

Напр. Xiaomi Mi A3 = laurel_sprout. После потърси трите неща, нужни за твоя codename, в LineageOS wiki, GitHub или XDA форума:

🌳 device tree — описва хардуера на телефона.
📦 vendor — затворените драйвери (blobs), обикновено от TheMuppets.
🧩 kernel source — ядрото на Linux за този модел.

⚠️ Задължително Qualcomm (Snapdragon) устройство — не Exynos, не MediaTek. DODO е правено и тествано само на Qualcomm; само там работят правилно ядрото, USB защитите и NetHunter. При Samsung избери Snapdragon варианта (често международните/US модели), не Exynos.

4

Свали DODO базата (сорс кода)

Направи папка и изтегли LineageOS 22.2 (Android 15) плюс DODO overlay-а. Първото теглене е дълго (над 100 GB, час-два според интернета):

mkdir -p ~/dodo && cd ~/dodo
repo init -u https://github.com/LineageOS/android.git -b lineage-22.2
repo sync -c -j8
git clone https://github.com/gpsn0w/dodo-os vendor/dodo

Сега кажи на кода откъде да вземе дърветата за твоя телефон. Направи файл .repo/local_manifests/roomservice.xml и сложи вътре редове като тези (с твоите реални линкове и codename):

<?xml version="1.0" encoding="UTF-8"?>
<manifest>
  <project name="LineageOS/android_device_ПРОИЗВОДИТЕЛ_CODENAME"
           path="device/ПРОИЗВОДИТЕЛ/CODENAME" remote="github" />
  <project name="TheMuppets/proprietary_vendor_ПРОИЗВОДИТЕЛ_CODENAME"
           path="vendor/ПРОИЗВОДИТЕЛ/CODENAME" remote="github" />
  <project name="LineageOS/android_kernel_ПРОИЗВОДИТЕЛ_ЧИПСЕТ"
           path="kernel/ПРОИЗВОДИТЕЛ/ЧИПСЕТ" remote="github" />
</manifest>

После дръпни и тези нови дървета:

repo sync -c -j8
5

Включи DODO overlay-а

За да получи телефонът ти DODO приложенията, overlay-ите, microG и настройките, добави един ред накрая на файла
device/ПРОИЗВОДИТЕЛ/CODENAME/lineage_CODENAME.mk:

$(call inherit-product-if-exists, vendor/dodo/dodo.mk)

💡 Това е цялата магия на DODO — един ред, който „закача" целия overlay върху чистия LineageOS.

6

Компилирай системата

Зареди build средата и пусни компилацията. LineageOS сам хваща правилната версия през breakfast — не е нужно да помниш release кода:

source build/envsetup.sh
breakfast CODENAME
brunch CODENAME

⏳ Първият билд отнема 2–5 часа (следващите са много по-бързи). Компютърът ще се натовари силно — това е нормално.

Като свърши, готовият zip е тук:
out/target/product/CODENAME/lineage-22.2-*.zip

💡 Ако нещо гръмне, прочети последните редове в терминала — там пише кой модул е паднал и защо.

7

Флашни зипа на телефона

⚠️ Флашването трие телефона — бекъпни си данните първо.

Xiaomi / Qualcomm: зареди телефона в recovery, направи Factory reset / Format data, после от компютъра:

adb sideload out/target/product/CODENAME/lineage-22.2-*.zip

Samsung: флашни през Odin (Windows) или Heimdall (Linux) — fastboot не работи при Samsung.

След флашването рестартирай. Първото стартиране е бавно (1–2 мин) — нормално е.

8

Публикувай в GitHub (по желание)

Сподели билда си, за да го ползват и други хора с твоя телефон:

gh repo create dodo-os-CODENAME --public
gh release create v1 \
  out/target/product/CODENAME/lineage-22.2-*.zip \
  --title "DODO OS · CODENAME" \
  --notes "Android 15 · DODO overlay · неофициален билд"

⚠️ Качвай само чистата версия (без root и без лични неща вътре). Опиши устройството, версията и че е неофициален билд в release бележките.

⚠ Компилирането иска силен компютър (16GB+ RAM, ~300GB диск, Linux). Не е за начинаещи — но е напълно постижимо. DODO OS е отворен код под AGPL-3.0; името и логото остават запазени.
