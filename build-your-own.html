За други телефони

Направи го за твоя телефон

DODO OS е отворен код. Ако имаш друго устройство — Pixel, Samsung, Xiaomi, Motorola — можеш да си направиш твое DODO OS, като смениш device tree-то.

1

Намери device tree за твоя телефон

Търси в LineageOS или GitHub по името на твоя модел (напр. „lineage device <телефон>"). Трябват ти: device tree + vendor tree + kernel source. Повечето популярни телефони ги имат поддържани.

2

Клонирай източника на DODO OS

Вземи LineageOS 22.2 база и DODO vendor overlay:

repo init -u https://github.com/LineageOS/android.git -b lineage-22.2
repo sync -j8
git clone https://github.com/gpsn0w/dodo-os vendor/dodo
3

Добави твоя device tree

Сложи дърветата за твоя телефон в device/<марка>/<codename> и kernel/<марка>/<soc>. Включи vendor/dodo/dodo.mk в inherit списъка на устройството.

4

Компилирай

Избери устройството си и компилирай целия ROM:

source build/envsetup.sh
lunch lineage_<codename>-bp1a-userdebug
mka bacon
5

Флашни и сподели

Получаваш подписан зип за твоето устройство в out/target/product/<codename>/. Флашваш го по същия начин като N100 ROM-а. Ако добавиш ново устройство — сподели го в GitHub, за да го ползват и други.

⚠ Компилирането на ROM иска силен компютър (16GB+ RAM, 300GB диск, Linux). Първият билд отнема 2–5 часа. Не е за начинаещи — но е постижимо.
