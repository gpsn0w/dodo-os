Инсталиране

  1. Отключи bootloader-а: Developer options → OEM unlocking, после fastboot flashing unlock
  2. Boot в recovery → Apply Update → Apply from ADB
  3. На компютъра: adb sideload dodo-os-billie2.zip
  4. Reboot system now — и WiFi работи 🎉
⚠️ Честно: bootloader-ът на N100 не може да се заключи пак с твой ключ (хардуерно), затова DODO OS не дава verified boot като GrapheneOS. Но privacy, sandbox и изтриване работят напълно.
