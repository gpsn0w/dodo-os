# 🦤 Dodo OS — как е направено (пълен дневник)

Този документ описва как е построен **Dodo OS** за OnePlus Nord N100 (BE2013 / **billie2**) — стъпките, решенията и капаните, за да може да се повтори.

## Каква е Dodo OS
Privacy-focused Android базиран на **LineageOS 22.2 (Android 15)** за billie2, с вградени:
- 📦 **microG** — Google услуги в sandbox (работи чрез вградената в LineageOS signature spoofing)
- 🎨 **Lawnchair** — Pixel-стил launcher + собствен DODO launcher/dialer/икони
- 🔒 **F-Droid, Aurora Store, Wasted, Duress** — privacy приложения
- 🎬 Собствена **DODO boot анимация**
- 📶 Компилирано от източник → **работещо WiFi** (`qca_cld3_wlan.ko` е вграден)

## Основа и репа
- Източник: **LineageOS `lineage-22.2`** (`https://github.com/LineageOS/android.git`)
- Device репа (`sohaibdevelop1290-oss`, клон `lineage-22.2`):
  - `android_device_oneplus_billie2` → `device/oneplus/billie2`
  - `proprietary_vendor_oneplus_billie2` → `vendor/oneplus/billie2`
  - `android_kernel_oneplus_sm4250` → `kernel/oneplus/sm4250`
  - `android_hardware_oneplus` → `hardware/oneplus`
- Local manifest: [`manifest/billie2-local-manifest.xml`](../manifest/billie2-local-manifest.xml)

## Как се строи
1. `repo init -u https://github.com/LineageOS/android.git -b lineage-22.2 --git-lfs`
2. Слагаш local manifest-а в `.repo/local_manifests/`
3. `repo sync -c -j6`
4. Слагаш `vendor/dodo/` ([Android.mk](../vendor-dodo/Android.mk) + [dodo.mk](../vendor-dodo/dodo.mk)) с APK-тата
5. Закачаш `dodo.mk` към `device/oneplus/billie2/lineage_billie2.mk`:
   `$(call inherit-product-if-exists, vendor/dodo/dodo.mk)`
6. Билд скрипт: [`scripts/dodo-compile.sh`](../scripts/dodo-compile.sh)
   - `source build/envsetup.sh` (⚠️ **БЕЗ `set -u`** — чупи LineageOS envsetup)
   - `breakfast billie2` (⚠️ **НЕ** `lunch lineage_billie2-userdebug` — на A15 иска нов формат)
   - `mka bacon -j6`
7. Готов ROM: `out/target/product/billie2/lineage-22.2-*-billie2.zip`

## Капани, които решихме (важно!)
| Проблем | Решение |
|---------|---------|
| `set -u` чупи envsetup.sh | Билд скриптът без `set -u` |
| `lunch lineage_billie2-userdebug` невалиден | Ползвай `breakfast billie2` |
| Липсващи HAL модули (`livedisplay@2.1`, `touch@1.0`) | Смени с AIDL имена: `vendor.lineage.livedisplay-service.oneplus`, `...touch-service.oneplus` в `device.mk` |
| `openssl/opensslv.h` липсва при kernel | `sudo apt install libssl-dev` |
| `uses-library` mismatch (AuroraStore) | `LOCAL_ENFORCE_USES_LIBRARIES := false` на всеки APK + `PRODUCT_BROKEN_VERIFY_USES_LIBRARIES := true` |
| boot анимация конфликт | Ползвай soong: `SOONG_CONFIG_lineage_bootanimation_prebuilt_file := vendor/dodo/bootanimation.zip` |
| microG signature spoofing | LineageOS 22.2 вече го има вградено (само за microG пакетите) |

## Хардуер / машина
- Ubuntu 26, 14 GB RAM (тясно — прави се 24 GB swap), 12 ядра
- Билдът: ~90 GB код, часове компилация

## Флашване на N100 (капаните тук са специфични!)
1. Телефонът трябва да е на **OxygenOS 11 (11.0.15)** firmware — ROM-ът НЕ носи firmware, разчита на този на телефона. (BE2013 стига до 11.0.15 през OTA обновление.)
2. **Bootloader отключен** (`fastboot flashing unlock`) — MSM/OOS флаш го заключва пак!
3. billie2 е **A/B с отделни `recovery_a`/`recovery_b` дялове** (recovery-то НЕ е в boot!)
4. Bootloader-ът не флашва големи образи (96 MB) и не сменя слотове → ползвай **fastbootd** (`fastboot reboot-fastboot`, може да иска 2 опита)
5. Във fastbootd: `fastboot flash recovery_a recovery.img` + `recovery_b`
6. Reboot to recovery → DODO recovery → **Format data** (задължително от друг OS) → Apply from ADB → `adb sideload lineage-22.2-*.zip`

## Честна граница
N100 bootloader-ът **не се заключва пак с твой ключ** → няма GrapheneOS-ниво verified boot. Dodo OS е силен privacy ROM, не Graphene заместител.
